# 🔧 Восстановление отзывов и исправление изображений

## Проблема
- Отображается только 3 отзыва вместо всех
- Некорректные фото в популярных карточках

## ✅ Решение

### На сервере выполните:

```bash
# 1. Перейдите в директорию проекта
cd /opt/arenda-neba

# 2. Получите последние изменения
git pull origin main

# 3. Остановите приложение
pm2 stop arenda-neba

# 4. Восстановите все отзывы из бекапа (если есть)
node restore-all-reviews-from-backup.js

# ИЛИ восстановите стандартные отзывы (10 отзывов)
node restore-reviews.js

# 5. Проверьте и исправьте изображения
node check-and-fix-images.js

# 6. Запустите приложение
pm2 start arenda-neba

# 7. Проверьте результат
curl http://localhost:3000/api/reviews | jq length
# Должно показать больше 3 отзывов
```

## Что делают скрипты:

### `restore-all-reviews-from-backup.js`
- Ищет бекап базы данных
- Восстанавливает ВСЕ отзывы из бекапа в текущую базу
- Показывает список всех найденных отзывов

### `restore-reviews.js`
- Восстанавливает 10 стандартных отзывов (включая те 3, что показываются сейчас)
- Безопасно добавляет отзывы (не удаляет существующие)

### `check-and-fix-images.js`
- Проверяет все изображения в популярных карточках
- Исправляет неправильные пути к изображениям
- Показывает статистику по изображениям

## Проверка результата:

```bash
# Проверьте количество отзывов
curl http://localhost:3000/api/reviews | jq 'length'

# Проверьте популярные карточки
curl http://localhost:3000/api/popular-cards | jq '.[] | {title, image_url}'
```

## Если бекап не найден:

Скрипт `restore-all-reviews-from-backup.js` автоматически проверит:
- `./database.db.backup`
- `./backups/database.db`
- `/opt/arenda-neba/database.db.backup`

Если бекап не найден, используйте `restore-reviews.js` для восстановления стандартных отзывов.
